# 🐍 SobanPy

### Python Error Detector & AI Explanation Tool

SobanPy is a beginner-friendly Python tool that detects common Python errors and uses Google Gemini AI to explain them in simple language.

The goal is to help Python learners understand **what went wrong, why it happened, and how to fix it.**

---

## ✨ Features

- 🔍 Detects Python syntax and runtime errors
- 📍 Shows the error line number
- 📝 Shows the original error message
- 🤖 Uses Gemini AI for simple explanations
- 💡 Provides a corrected code example
- 🖥️ Simple Streamlit interface
- 📱 Works on desktop and mobile browsers
- 🔐 API key stored securely using `.env`

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- Google GenAI SDK
- python-dotenv
